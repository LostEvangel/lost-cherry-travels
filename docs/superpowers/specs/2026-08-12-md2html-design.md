# Markdown → HTML 导出工具设计

**日期：** 2026-08-12  
**状态：** 待确认  
**范围：** 本地预览 + 单页分享 + 公众号粘贴

## 目标

为 `lost-cherry-travels` 旅行笔记提供一键导出：把行程目录下的 Markdown 转成美观 HTML。你无需手写代码，只需运行一条命令。

## 使用场景

1. **本地预览**：浏览器打开 HTML，含配图
2. **分享给别人**：自包含样式的单页 HTML，可离线打开
3. **公众号粘贴**：另出微信兼容版，浏览器全选复制后粘贴到公众号编辑器

## 方案

仓库内 Node 小工具（方案 A），默认主题：**杂志暖色**。

### 命令

```bash
node tools/md2html.mjs <markdown路径>
```

可选：

```bash
node tools/md2html.mjs <markdown路径> --out <输出目录>
```

未指定 `--out` 时，HTML 写在源 Markdown 同目录。

### 输出

对 `trips/2026-烟台威海/攻略.md` 会生成：

| 文件 | 用途 |
| --- | --- |
| `攻略.html` | 浏览器预览 / 发给别人 |
| `攻略.wechat.html` | 公众号：打开 → Ctrl+A → Ctrl+C → 粘贴编辑器 |

### 杂志暖色（默认）

- 背景白、正文深灰、标题暖橙
- 引用左侧暖色竖线 + 浅暖底
- 图片居中、圆角、最大宽度 100%
- 中文行高约 1.75–1.8，易读
- 表格可读（行程总览等）

### 技术要点

- 运行时：本机已有 Node / npm
- 依赖：`markdown-it`（解析 Markdown；表格、链接、图片）
- 相对图片路径（如 `./assets/map1.png`）在 HTML 中保持相对，与 Markdown 同目录打开时图片正常
- **分享版**：完整 HTML 文档，CSS 写在 `<style>` 内
- **微信版**：内联样式为主，避免依赖外链 CSS；接受微信编辑器会过滤部分样式（圆角、部分边框等），设计时做可降级样式

### 不做

- 不做成网站/静态站生成器
- 不自动部署
- 不改 Markdown 原文内容
- 首版不提供多主题切换（需要时可后续加）

## 文件结构

```text
tools/
  md2html.mjs          # 入口脚本
  themes/
    magazine-warm.css  # 杂志暖色（分享版）
package.json           # 若尚无则新增，仅声明工具依赖
```

## 验收标准

1. 对现有 `trips/2026-烟台威海/攻略.md` 导出成功
2. `攻略.html` 浏览器打开：标题层级、表格、引用、两张地图图可见且样式偏杂志暖色
3. `攻略.wechat.html` 可在浏览器打开并全选复制
4. README 中有一句使用说明

## 风险与说明

- 微信编辑器会剥离部分 CSS；微信版以「粘贴后仍可读」为优先，视觉效果可能弱于分享版
- 发给别人时需连同 `assets/` 一起打包，或后续再做图片内嵌（首版不做内嵌）
